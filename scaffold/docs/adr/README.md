# Architecture Decision Records

This service's decision log. Each ADR captures one significant decision as
**Context → Decision → Consequences**, following the platform discipline
([`../platform/adr-discipline.md`](../platform/adr-discipline.md)); copy
[`../platform/adr-template.md`](../platform/adr-template.md) to `NNNN-title.md` (next
number) to start one.

New decisions get the next number; superseded ADRs are marked, not deleted. **Ask before
deviating** from any `Accepted` ADR — a deviation is its own new ADR.

Platform-wide decisions (ones that bind every service) live in the **platform repo's**
`adr/`, not here; this log holds only what binds *this* service.
