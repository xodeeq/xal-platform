# Concepts — a curriculum

Durable, human-facing **concept notes** for this service. Each note teaches one topic
end-to-end (the problem it solves → how it works from first principles → the tradeoff space
→ what *this* repo chose and why → comprehension checks → go deeper), anchored to **real
code in this repo and the relevant ADR**. Notes are generated and kept honest by the
`concept-note` skill; the form and rules are the platform spec
([`../platform/concept-note-structure.md`](../platform/concept-note-structure.md)).

This index doubles as a **human onboarding path**: read it top to bottom. Notes are
sequenced so each builds on the ones above it. When a note is added, slot it into the order
that keeps that true.
