## Decisions & lessons captured

- **Gate 1 required a decidability decision, and it was not free.** "Inside an auth citation"
  was not mechanically determinable: 18 of 24 hits sat in citation blocks, 6 did not, and two
  marker spellings were in use. Rather than a fuzzy heuristic, `**Auth ref:**` /
  `**Auth reference.**` became canonical region markers plus an explicit `<!-- auth-ref -->`
  paragraph escape — chosen over restructuring the prose, because rewriting normative content
  is a larger semantic change than a patch bump implies, and the ENTRYPOINT gotcha reads
  better with its example inline.
- **Gate 3 had to model the vendored context, not the filesystem.** All 8 unresolved links in
  the repo are scaffold → `docs/platform/<file>` forward references, legitimate because that
  directory is empty until a seeded service first syncs. Validating them against
  `sync/manifest` is *stricter* than a file check: it also catches a scaffold link to a spec
  file nobody vendors, which would dangle forever in every future service.
- **The audit was widened before fixing, and confirmed rather than expanded the scope.** All
  eight manifest files checked, plus reference-style / HTML / autolink / image / `./` forms —
  none exist. The three reported links were the complete set.
- **Promotions:** the 2026-08-12 "Vendored spec carries links that dangle in every consumer"
  entry → `promoted→` **CLOSED**, citing both PRs. It had predicted its own fix ("its own PR
  + a patch `VERSION` bump"); the closure records the prediction holding.
- **New lesson (open):** see below — the gate found three bugs in itself, which is the entry
  worth keeping.

## Gate status

`scripts/check.sh` — **ALL GATES PASSED** (4/4), ~1.4s. Green locally and in CI
([run 31644217824](https://github.com/xodeeq/xal-platform/actions/runs/31644217824), this
repo's first-ever CI run).

**Each gate was tested against a deliberate violation**, because a gate that cannot fail is
worthless:

| Scenario | Want | Got |
|---|---|---|
| Leak in normative prose | fail | ✅ exit 1 |
| Same text inside a citation | pass | ✅ exit 0 |
| Same text in an escaped paragraph | pass | ✅ exit 0 |
| Dangling relative link | fail | ✅ exit 1 |
| **Reintroduce this session's exact bug** | fail | ✅ exit 1 |
| Scaffold → never-vendored file | fail | ✅ exit 1 |
| Manifest → missing spec file | fail | ✅ exit 1 |
| Corrupt `platform-sync.sh` | fail | ✅ exit 1 |
| Restored repo | pass | ✅ exit 0 |

That testing found **three real bugs in the gate itself**, all fixed before merge:
1. **awk has no `\b`** — POSIX awk reads it as backspace, so the CLAUDE.md pattern silently
   matched nothing for `dotnet` and `Auth.X`. `grep -E` now finds hits; awk only computes
   which lines are excused, keeping a single pattern.
2. **`comm` assumes lexically sorted input** — line numbers sorted with `sort -n` are in a
   different order (`"127" < "30"` lexically), so it mis-paired. Set difference is now
   `grep -vxF`, which is order-independent, with a guard for the empty-pattern case.
3. A paragraph-form citation followed by a bullet list fell out of its region after the first
   bullet.

Runtime was ~120s on the first working version; `dirname` plus two `grep`s **forked per link**
dominated everything at this repo's size. Membership is now a bash `case` glob → ~1.4s.
